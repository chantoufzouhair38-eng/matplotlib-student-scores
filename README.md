# Matplotlib Practice – Student Exam Scores

## 📌 About the Project

This project is a beginner-level Python data visualization exercise using **Pandas** and **Matplotlib**.

The dataset contains exam scores for 8 students across three subjects: Math, Science, and English.

The goal is to practice creating different types of charts and understanding how to visualize data.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib

## 📊 Visualizations

The project includes the following visualizations:

1. Bar Chart – Math scores for each student.
2. Line Plot – Comparison between Math and Science scores.
3. Pie Chart – Average scores by subject.
4. Histogram – Distribution of Math scores.
5. Scatter Plot – Relationship between Math and Science scores.
6. Box Plot – Comparison of score distributions across the three subjects.

## 🎯 What I Learned

- Creating visualizations with Matplotlib.
- Working with DataFrames using Pandas.
- Understanding different chart types.
- Comparing and analyzing data distributions.
- Customizing plots with titles, labels, and grids.
